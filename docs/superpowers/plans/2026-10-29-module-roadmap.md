# 模块化对标路线（nightly OpenBot）

> 2026-10-29 · 停止点状迭代。
> 一个模块做完再开下一个；模块内按 schema → service → transport → UI → E2E 收口。
> 形态固定：DSH 插件。

## 一、规则

```text
1. 一次只做一个模块
2. 模块没有 exit criteria 不算完成
3. 不跨模块加功能
4. 每个模块必须有：
     schema / 持久化
     service / runtime
     transport
     UI
     一条端到端场景
     回归测试
     文档
5. 点状优化只能作为模块收口的一部分，
   不再单独开“按钮/文案/一处入口”任务
```

## 二、模块与现状

| 模块 | 现状 | 主要缺口 |
|---|---|---|
| M0 表面一致性 | 80% | 公告合并、活动板、概览去重 |
| M1 同事与工作区生命周期 | 85% | profile/panel 状态、团队关联边界、归档入口 |
| M2 运行控制 | 65% | 统一控制面、队列可见、Reassign UI、团队任务归档 |
| M3 会话与协作 | 45% | 共享频道、群聊讨论、文件/图片/reaction |
| M4 上下文与记忆 | 60% | 自动 compact 阈值、同事 journal |
| M5 创建与上手 | 85% | 模板市场、导入、保存前 review 完整度 |
| M6 治理与可观测 | 70% | 诊断导出、安装医生、审计视图 |
| M7 浏览器/电脑 | 0% | 宿主能力，后置 |
| M8 分发与产品化 | 25% | i18n、市场、移动端（后置） |

## 三、模块定义

### M0 表面一致性

```text
公告：群公告 + 分区公告 = 一个入口
活动板：并进任务详情时间线
概览：只留入口，不重复列表
```

Exit：

```text
同一件事只有一个地方
旧数据可见可编辑
无重复菜单
```

### M1 同事与工作区生命周期

```text
创建 / 编辑 / 归档 / 恢复
独立 workspace
团队关联边界
profile / 模型 / 权限 / 通知 / 面板状态
```

Exit：

```text
一个同事从创建到归档到恢复，全流程可用
工作区不串、不删
团队关联冲突明确
```

### M2 运行控制

```text
队列可见（位置、等待原因）
pause / resume / cancel
Stop / Reassign / Archive / Restore
一个任务一个 owner
显式 delegation
团队任务归档/恢复
```

Exit：

```text
用户在一个控制面能回答：
  在跑什么
  在等什么
  为什么停
  下一步点哪里
```

### M3 会话与协作

```text
永久同事 Chat
共享频道
群聊讨论（2–6 同事）
@mention / needs-you
Agent 间消息 / 回复
文件 / 图片 / reaction
```

Exit：

```text
同事之间能讨论、能递文件
团队仍以任务/评审为交付核心
```

### M4 上下文与记忆

```text
自动 compact 阈值
同事 journal
团队记忆 revision
上下文压力可见
```

Exit：

```text
长会话不丢关系
同事能说清做过什么
```

### M5 创建与上手

```text
预设 / 一句话 / 保存前 review
模板 / 导入
首次使用路径
```

Exit：

```text
新用户 1 分钟内有一个可用同事
创建前能看清将得到什么
```

### M6 治理与可观测

```text
审批 / 权限
审计视图
诊断导出
安装医生
```

Exit：

```text
每个动作可解释
出问题能自检
```

### M7 浏览器/电脑

```text
宿主浏览器 / 容器
```

宿主能力，单独立项。

### M8 分发与产品化

```text
i18n
市场
移动端/远程
```

后置，不阻塞 M0–M6。

## 四、顺序

```text
M0 表面一致性      ← 当前
M1 生命周期收口
M2 运行控制
M3 会话与协作
M4 上下文与记忆
M5 创建收口
M6 治理与可观测
M7 浏览器/电脑
M8 分发/产品化
```

## 五、每个模块的交付物

```text
1 份模块说明
  范围 / 非范围
  数据模型
  用户场景
  验收

1 条端到端演示
  可重复执行

1 组回归测试

1 次独立验收 + 1 次独立评审
```

## 六、不做

```text
点状“再加一个按钮”
点状“再改一处文案”
跨模块顺手优化
没有 exit criteria 的“差不多了”
```
