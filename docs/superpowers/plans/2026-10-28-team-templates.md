# 团队模板 — 首个可用团队

> 2026-10-28 · 目标：让新用户不用从零填团队，5 分钟内发起第一次团队任务。
> 约束：不改侧栏、不改团队页结构、不新增导航；只在现有“新建团队”里加预设。

## 定位

不做模板市场、不做模板编辑器、不做 AI 生成。
只做 3 个内置模板，填充现有创建流程。

```text
新建团队
  [空白]
  [代码库体检队]
  [功能开发队]
  [发布检查队]
```

## 模板内容

### 1. 代码库体检队

```text
团队名：代码库体检
成员：
  Leader × 1
  审查员 × 2（按目录/模块分片）
  复核员 × 1
任务：
  分片审查（每个审查员一条）
  交叉复核
  汇总报告
验收：
  每条发现带文件/行号/证据
  复核员 pass 才算完成
```

### 2. 功能开发队

```text
团队名：功能开发
成员：
  Leader × 1
  实现 × 1
  测试 × 1
任务：
  实现
  验证
  交付说明
验收：
  实现者不自评
  验证通过才算完成
```

### 3. 发布检查队

```text
团队名：发布检查
成员：
  Leader × 1
  构建 × 1
  回归 × 1
任务：
  构建
  回归
  发布清单
验收：
  构建产物可复现
  回归清单逐项勾选
```

## 行为

```text
点模板 → 在现有新建团队表单预填：
  团队名
  成员角色 / 数量
  3 条初始任务
  每条任务的验收标准
  默认工作区

用户仍可逐项修改
创建后不绑定模板
空白创建完全不变
```

## 不做

```text
模板市场
模板编辑器
模板分享/导出
AI 自动生成团队
模板版本/更新
```

## 验收

1. 新建团队出现 4 个选项：空白 + 3 模板。
2. 选模板后，名称、成员、任务、验收标准被预填。
3. 所有预填项可编辑；取消不创建。
4. 创建后与手填团队无差别，不出现“模板绑定”。
5. 空白创建路径不变。
6. `npm run check` 全绿。

## 任务拆分

### T1 审计

- 现有新建团队对话框、`team.createDraft` 输入、成员/任务字段。
- 模板应放在哪个现有表单层，不新增页面。
- 确认无需 schema/transport 变化。

### T2 模板定义 + 表单映射

- 3 个内置模板常量。
- 将模板映射到现有 draft 输入。
- 不新增 schema/transport；不改创建后数据。

### T3 原生 UI

- 现有新建团队对话框顶部加模板选择。
- 选中后预填，字段仍可编辑。
- 空白路径不变。
- 原生控件 / token；无 body/fixed/z。
