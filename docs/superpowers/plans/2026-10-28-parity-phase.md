> 2026-10-28 · 用户授权：按此队列直接推进，不再逐项评审。
> 目标：用户从竞品切过来，10 个核心日常任务至少 9 个不需要回去。

```text
群聊 / 单聊 / 团队线程
模型 + 思考等级
头像 / 吉祥物
助手记忆 + 采纳
团队记忆 + Leader-only 注入
分区共享指令
分区批量设置
分区导出 / 导入
token 用量只读面板

```

## 执行顺序

### 1. 团队模板

状态：已排，等 usage-panel 收尾后开。

```text
新建团队：空白 + 代码库体检 + 功能开发 + 发布检查
预填名称 / 成员 / 任务 / 验收
创建后不绑定模板
```

验收：选模板后可直接创建，字段可改，空白路径不变。

### 2. 团队公告

```text
团队页顶部一条当前公告
仅用户可写，成员只读
不做公告历史、已读回执
```

验收：成员下一轮能看到；编辑有权限；空公告不显示。

### 3. group-batch 三个 polish

```text
换模型时清空/收窄思考等级
应用后可重试，不必关闭重开
no-op 显示“未变化”，不是“已更新”
```

验收：三个交互都有测试。

### 4. 首次使用引导

```text
新建团队后：
  一个可完成的样例任务
  明确的下一步按钮
  不要求先理解 Leader/线程/评审
```

验收：新用户建完团队 10 分钟内能完成第一个任务。

### 5. 通知 / 未读 / 归档入口

```text
统一入口查看：
  待审批
  需要我回复
  未读团队/助手
  已归档团队/助手/线程
```

验收：三类事件都能从一处进入并清掉；归档可查看。

### 6. 助手身份层级

```text
name 之外增加：
  title（职能）
  blurb（一句话介绍）
新建助手可填，侧栏/详情可显示
```

验收：同名不同职能可区分；旧助手 title/blurb 为空不报错。

### 7. 搜索

```text
跨团队 / 助手 / 线程搜索
标题 + 简介 + 最近消息
点击直达原生 Session 或团队页
```

验收：三类对象都能被搜到；空结果有明确状态。

### 8. 归档恢复

```text
归档团队 / 助手 / 线程可恢复
恢复不重建会话
不可恢复时给出原因
```

验收：归档→恢复→原数据仍在。

### 9. 对齐审计

```text
列 10 个核心日常任务
逐项标注：原生 / 已对齐 / 仍缺 / 宿主没有
```

完成标准：

```text
至少 9/10 不需要回竞品
剩余 1 项必须是宿主能力限制，不是我们没做
```

```text
一次只开一个团队
每项：实现 → 独立验收 → 独立评审 → 提交 → 推送
不做大结构改；不改原生聊天/输入框
UI 优先原生 Slot / 原生控件，不再扩 DOM 浮层
共享文件路径限定提交，禁止 stash/checkout/amend/reset
```
